How it works

Your phone is the build server

The maker app clones its own installed APK, writes a fresh binary manifest and a config file, swaps the icon, signs the result with a built-in pure-Java signer, then asks Android to verify it. No cloud, no PC.

Features

Everything in one clean maker

Each generated app has a Splash screen (your icon and “Made by silencorex”) and a very advanced WebView screen.

Smart back control

YouTube back never walks to Google, and one back never kills the app. Modes: Smart, Home, Exit, System. Skip-hosts, double-back or confirm dialog.

Live preview + back testerNew

Run the real app engine inside the maker. Press Back and see every decision in a log: mode, rule, skipped hop, tab switch, exit.

Tabs & drawerNew

Bottom tabs (2–5) or a side drawer (2–12) with multiple URLs. Each tab keeps its own page and history.

Per-site rulesNew

One line per site, for example youtube.com | back=skip, ua=desktop. Control back, external links, user agent, JS, zoom, dark mode, cache and blocking.

Ad & tracker blockNew

Built-in host list, your own extra hosts, and cosmetic CSS that hides ad boxes.

App lockNew

Phone screen-lock / fingerprint, or your own PIN. The APK keeps only a salted SHA-256 hash. Lock again after N seconds.

JavaScript bridgeNew

Headers & loginNew

Custom request headers and HTTP basic auth, sent only to your own site.

FAQ

Questions

Can I write Java and XML inside the maker?

Not compile them, because Android phones have no Java compiler. Write the Activity and layout in Sketchware inside the maker app; generated apps are clones, so they include your code. Studio then declares and launches it.

Why does the build say a class is not in any dex?

You declared an Activity, Service or start class that is not in the maker or in an imported .dex. The app would crash when starting it. Add the class in Sketchware, or import its .dex in Libraries.

The icon did not change.

The maker’s own icon must be a plain PNG, not an adaptive XML icon.

Install is blocked.

Allow “Install unknown apps” for the maker and add the REQUEST_INSTALL_PACKAGES permission, or install the saved file from Downloads/Silencorex.

Does it work with ProGuard on?

No. R8 would remove the shell classes. Keep it off.

Is the app lock PIN safe?

The built app stores a salted SHA-256 hash, not the PIN. Like any client-side lock, it stops casual access, not someone who unpacks the APK.
